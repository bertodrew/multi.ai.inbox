Use dedicated MCP

Connect Claude or Hermes to this fork’s native MCP server to read and change mail domain settings without opening the panel.

/api/mcp.php
  • list_domains— list all mail domains with quota, aliases and active state
  • get_domain_settings— full settings of one domain (quota, DKIM, relay…)
  • set_domain_settings— change only the attributes you pass, e.g. {"active":"1"}

            Hermes usage instructions
            

              Point the Hermes MCP client at the endpoint above with
              Authorization: Bearer <MAILCOW_API_KEY> (the read-write key from
              mailcow.conf). Then prompts like “list domains and show the settings
              of example.com” call list_domains and
              get_domain_settings; changes go through set_domain_settings.
            

          


          

            The mailcow API must be enabled (System → Configuration → Access → API) with the
            docker subnet allowed in API_ALLOW_FROM. The key is read from
            mailcow.conf at runtime — it is never written to this page or the repository.
